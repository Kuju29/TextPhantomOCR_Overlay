###  1.2 Extension Installation

#### **Option – Manual Install**
1. Download and extract the **Source Code** for your version.
2. Run the builder `build.bat` When finished, two folders will be created: `dist/` and `packages/`
3. Open Chrome → Go to `chrome://extensions/`.  
4. Enable **Developer Mode** (top right).  
5. Click **Load unpacked**.  
6. Select the extracted folder in `dist/`.  

###  1.3 Hugging Face API

#### **Option - Public API**

1. Install and open **TextPhantom**.
2. Click **Refresh API URL**.
3. **Start translating! 🎉**

> Shared with other users, so it may be slower during high usage.

#### **Option - Your Own API**

1. Open the [TextPhantom Hugging Face Space](https://huggingface.co/spaces/plan291037/TextPhantom-v4.0.0/tree/main).
2. Click **⋯ → Duplicate this Space**.
3. Wait until **Running**.
4. Click **⋯ → Embed this Space** and copy the URL.
5. Paste it into **Custom API URL**.

> Free cloned Spaces may stop automatically after being unused for up to 48 hours.

## 🎉 2. Getting Started

| What you do | What TextPhantom does |
| :--- | :--- |
| 🖼️ **Right-click an image** | 🔍 Translates **only that image** |
| 📚 **Right-click an empty area** | 🔍 Translates **all images on the page** |
| 🚧 **`Translates tab` → Page actions** | Alternative buttons for websites where right-click translation doesn't work |

### 🎨 Choose How Translations Appear

Open the `Translate tab` and select a **Mode**.

| Mode | How it works | Result |
| :--- | :--- | :--- |
| **Image** | Original image → **Google Translate** → Translated image | Replaces the original with the translated image from Google Translate. |
| **Text** | Original image → **Detect text** → Place text over image | Keeps the original image and displays **HTML text over it**. Choose a **Source** below to decide how the text is translated. |

#### 💬 Mode Text → Source

When using **Text** mode, choose a **Source**:

| Source | Translation | How it works |
| :--- | :--- | :--- |
| 🌐 **Original** | **Browser Translate** | Shows the original detected text as HTML. Then use your browser's **Translate to...** to translate it. |
| 🔤 **Translated** | **Google Translate** | Uses Google's translated text and displays it as HTML over the original image. |
| 🤖 **AI** | **AI Model** | Sends the detected text to your selected AI model for translation. |

> 💡 **Free alternative:** Use **Text → Original**, then right-click an empty area of the page and select your browser's **Translate to...**


### 🤖 Using AI Translation

If you choose **Text → AI**, open the **AI option** tab and complete the basic setup:

| Step | Setting | What to do |
| :---: | :--- | :--- |
| **1** | **Provider** | Choose your AI provider |
| **2** | **API key** | Enter the API key for that provider |
| **3** | **Model** | Choose the AI model you want to use |
| **4** | **Set prompt** | Configure the translation instructions |

> ⚠️ **First time using a model?**  
> Open **Set prompt** and click **↺ Reset** to load the default prompt from the TextPhantom API.

### 🧰 Tools

Need to translate images stored on your computer? Open the `Tools tab`.

| Tool | What it does |
| :--- | :--- |
| 🖼️ **Select an image** | Open a local image and translate it with right-click |

## 🆓 Free AI Options

Looking for a free way to use **AI translation with TextPhantom**?  
You can run AI on your own computer with **Ollama**, or use **Hugging Face** in the cloud.

| Option | Runs on | API Key | Best for |
| :--- | :--- | :---: | :--- |
| 🖥️ **Ollama** | Your computer | ❌ No | Users who want **free local AI** and have enough system resources |
| ☁️ **Hugging Face** | Cloud | ✅ Yes | Users who don't want to run an AI model on their computer |



### 🖥️ Option 1 — Ollama (Local AI)

Run the AI model directly on your computer.  
**No AI API key required.**

1. **Install Ollama**  
   https://ollama.com/download

2. **Allow TextPhantom to connect**

   Open PowerShell and run:

   ```powershell
   $env:OLLAMA_ORIGINS="chrome-extension://*"
   ```

3. **Install an AI model**

   For example:

   ```powershell
   ollama pull gemma3
   ```

4. Open **TextPhantom → AI option → Provider → Local AI (Ollama)**.

5. Click **Connect** and select your installed model.

6. Go back to **Translate → Text → Source: AI** and start translating. 🎉

> **Ollama must be running** while using Local AI.


### ☁️ Option 2 — Hugging Face (Cloud AI)

Run the AI model in the cloud.  
**No local AI installation or powerful GPU required.**

1. **Create or sign in to Hugging Face**  
   https://huggingface.co/login

2. **Enable access to Google Gemma**  
   https://huggingface.co/google/gemma-3-27b-it  
   Click **Agree and access**.

3. **Create an API Token**  
   https://huggingface.co/settings/tokens

4. Enable:

   - ✅ **Read access to contents of all public gated repos you can access**

5. Copy the token and paste it into **TextPhantom → AI option → Hugging Face API Key**.

6. Select **Google Gemma** as your model.

7. Go back to **Translate → Text → Source: AI** and start translating. 🎉

> **Hugging Face is the easier option for computers that cannot comfortably run AI models locally.**
