คู่มือการใช้งาน TextPhantom

TextPhantom แปลข้อความในภาพมังงะ มังฮวา บนหน้าเว็บ คู่มือนี้มีภาพของหน้าต่างจริง ตัวเลขในวงกลมบนภาพตรงกับคำอธิบายข้อเดียวกันด้านล่าง ชี้หรือแตะที่ตัวเลขเพื่อดูว่าหมายถึงส่วนไหน

  • ชื่อปุ่มในคู่มือเขียนเป็นภาษาอังกฤษใน “เครื่องหมายคำพูด” ให้ตรงกับหน้าต่างจริง ถ้าคุณเปลี่ยนภาษาหน้าจอเป็น “ไทย” ชื่อปุ่มจะถูกแปล แต่ตำแหน่งเหมือนเดิม
  • อีเมล ตัวเลขเครดิต ชื่อเรื่อง และราคาในภาพเป็นเพียงตัวอย่าง
  • การตั้งค่าที่เลือกในหน้าต่าง TextPhantom ถูกบันทึกไว้ให้เอง ไม่มีปุ่มบันทึก
  • ชี้เมาส์ที่ชื่อตัวเลือกเพื่อดูคำอธิบาย (บนจอสัมผัสให้แตะที่ชื่อ) ชื่อที่มีคำอธิบายจะเปลี่ยนสีเมื่อชี้ ถ้าตัวเลือกใช้ไม่ได้ (เป็นสีจาง) คำอธิบายจะมีบรรทัดสีเหลืองบอกเหตุผล ข้อความที่อยู่ใต้ช่องจะมีเฉพาะสถานะหรือคำเตือนที่สำคัญตอนนั้น

1เริ่มต้นใช้งานใน 4 ขั้น

  1. ติดตั้งส่วนขยาย

    ติดตั้ง TextPhantom จากร้านส่วนขยายของเบราว์เซอร์ที่คุณใช้ (Chrome, Microsoft Edge, Opera, Firefox หรือ Thunderbird)

  2. เปิดหน้าต่าง TextPhantom

    คลิกไอคอน TextPhantom บนแถบเครื่องมือของเบราว์เซอร์ หน้าต่างเล็ก ๆ จะเปิดขึ้น ในคู่มือนี้เรียกว่า “หน้าต่าง TextPhantom”

  3. เลือกภาษาและวิธีแปล

    ที่แท็บ “Translate” เลือก “Target language” เป็นภาษาที่อยากอ่าน (เช่น “Thai”) ค่าเริ่มต้นของ “Text output” คือ “Lens translation” ใช้ได้ทันทีโดยไม่ต้องตั้งค่าอื่น ถ้าต้องการแปลด้วย AI ดูหัวข้อ 4

  4. แปลภาพบนหน้าเว็บ

    คลิกขวาที่ภาพแล้วเลือก “🔍 Translate this image” หรือคลิกขวาที่ว่างบนหน้าเว็บ แล้วเลือก “🔍 Translate all images on page” เพื่อแปลทุกภาพในหน้านั้น

    Open image in new tab
    Save image as…
    🔍 Translate this image

    เมนูจริงหน้าตาต่างกันเล็กน้อยตามเบราว์เซอร์ นอกจากคลิกขวา ยังเปิดปุ่มแปลบนหน้าเว็บได้ ดูหัวข้อ 3 ข้อ 6–7

2ส่วนบนของหน้าต่าง

ส่วนนี้แสดงอยู่ทุกแท็บ ใช้สลับหน้าและดูสถานะการเชื่อมต่อ

  1. ภาษาหน้าจอ เปลี่ยนภาษาของปุ่มในหน้าต่างนี้ (แปลด้วย Google Translate) เลือก “ไทย” ได้ ค่านี้ไม่เกี่ยวกับภาษาที่ใช้แปลภาพ
  2. สถานะเซิร์ฟเวอร์ ✅ เชื่อมต่อได้ · ⏳ กำลังตรวจ · ❌ เชื่อมต่อไม่ได้ ชี้เมาส์ค้างไว้เพื่อดูรายละเอียด
  3. “Translate” ตั้งค่าหลัก: วิธีแปล ภาษา ขนาดตัวอักษร และปุ่มบนหน้าเว็บ
  4. “AI settings” แท็บนี้มีเฉพาะเมื่อเลือก “Text output” เป็น “AI translation”
  5. “Tools” เปิดภาพจากเครื่อง, “Auto translate” และการตั้งค่าขั้นสูง
  6. ปุ่ม ? เปิดคู่มือนี้ในแท็บใหม่

3แท็บ Translate

ภาพนี้คือแท็บ “Translate” เมื่อเลือก “Text output” เป็น “Lens translation” บางช่องจะซ่อนหรือแสดงตามสิ่งที่เลือก

  1. “Mode”
    • “Google Lens (text)” วางคำแปลเป็นกล่องข้อความทับบนภาพ ปรับขนาดตัวอักษรได้ และแปลด้วย AI ได้
    • “Google Lens (image)” ได้ภาพที่ใส่คำแปลไว้ในภาพเลย (ช่อง “Text output” และ “Display” จะซ่อน)
  2. “Target language” ภาษาที่ต้องการอ่าน เช่น “Thai” (ซ่อนเมื่อเลือก “Original text” เพราะไม่ได้แปล)
  3. “Text output” (เฉพาะ “Google Lens (text)”)
    • “Original text” แสดงข้อความต้นฉบับที่อ่านได้จากภาพ
    • “Lens translation” คำแปลจาก Google Lens (ค่าเริ่มต้น)
    • “AI translation” แปลด้วย AI ต้องตั้งค่าที่แท็บ “AI settings”
  4. “↔️ Rotate Translated to fit language” (แสดงเฉพาะ “Lens translation”) จัดข้อความแนวตั้งให้อ่านแนวนอนได้ ปิดถ้าต้องการกล่องตามตำแหน่งเดิมของ Google Lens
  5. “Overlay font size” ขนาดตัวอักษรของคำแปล ปุ่ม − / + ปรับครั้งละ 10% ลากแถบได้ตั้งแต่ 50% ถึง 200% ปุ่ม ⟲ กลับเป็น 100% (ไม่มีในโหมด “Google Lens (image)”)
  6. “🔍 Translate all images on this page” แสดงปุ่ม “🔍 Translate all” ที่ขอบขวาของหน้าเว็บ ชี้เมาส์หรือแตะแถบเล็ก ๆ ที่ขอบขวาเพื่อเปิด
  7. “🔘 Translate buttons on images” แสดงปุ่ม 🔍 บนภาพเมื่อชี้เมาส์ที่ภาพ คลิกเพื่อแปลเฉพาะภาพนั้น
  8. “⬇ Download images” แสดงปุ่มดาวน์โหลดที่มุมขวาล่างของหน้าเว็บ บันทึกภาพทีละภาพหรือรวมเป็นไฟล์ ZIP ปุ่มนี้ไม่ได้เริ่มแปล

4เลือกแปลด้วย AI

  1. “AI settings” แท็บนี้ปรากฏหลังเลือก “AI translation” กดเพื่อตั้งค่า AI
  2. “Text output” เลือก “AI translation” (ใช้ได้เมื่อ “Mode” เป็น “Google Lens (text)”)

AI มี 3 แบบ เลือกแบบที่เหมาะกับคุณ

Manual “Manual · use your own key” ใช้ API key ของคุณเอง จ่ายกับบริษัท AI โดยตรง หรือใช้ AI ที่รันบนคอมพิวเตอร์ของคุณ (Local) ซึ่งไม่ต้องมี key Paid “Paid · TextPhantom credits” ไม่ต้องมี API key เข้าสู่ระบบด้วยอีเมล แล้วใช้เครดิต TP Login อยู่ในบัญชี Paid ใช้บัญชี ChatGPT, Claude, Gemini หรือ DeepSeek ของคุณ ใช้โควตาบัญชีนั้น ไม่ใช้เครดิต TP (ต้องมีสิทธิ์ AI Login ในบัญชี)

ถ้าไม่เห็นช่อง “AI service” แปลว่าเซิร์ฟเวอร์ที่ใช้อยู่ยังไม่เปิดบริการ Paid ใช้แบบ Manual ได้ตามปกติ

5AI แบบ Manual (ใช้ API key ของคุณ)

เลือก “AI service” เป็น “Manual · use your own key” แล้วตั้งค่าจากบนลงล่าง

  1. “Tokens used” จำนวนโทเคนที่ใช้กับ Provider และ Model ที่เลือก กดเพื่อเปิดดู มีปุ่ม “Reset” (เริ่มนับใหม่), “Detailed” (คำขอในรอบนี้และราคาโดยประมาณ) และ “History” (ประวัติการใช้)
  2. “AI service” เลือก “Manual · use your own key”
  3. “Provider” บริษัท AI ที่จะใช้ กลุ่ม “Cloud (needs API key)” เช่น Google Gemini, OpenAI, OpenRouter, Anthropic, Groq, DeepSeek ต้องมี key ส่วนกลุ่ม “Local (runs on your PC — no key)” ดูหัวข้อ 6
  4. “API key” วาง key ที่ได้จากบริษัท AI
  5. “(get key)” เปิดหน้าเว็บของบริษัทนั้นเพื่อสร้าง key
  6. “Model (required)” เลือกโมเดล (จำเป็น) เมื่อใส่ key ที่ใช้ได้ รายชื่อจะอัปเดตจากบริษัท AI
  7. “AI thinking” ให้ AI “คิด” ก่อนตอบ แนะนำ “Lowest available” ตัวเลือกขึ้นกับโมเดล ช่องนี้แสดงหลังระบบตรวจโมเดลแล้ว ถ้ายังเลือกไม่ได้ ชี้ที่ชื่อ “AI thinking” เพื่อดูเหตุผล ถ้าโมเดลทำตามที่บันทึกไว้ไม่ได้ จะมีคำเตือนสีเหลืองใต้ช่อง (การคิดอาจทำให้ใช้โทเคนมากขึ้น)

ตัวเลือกเพิ่มเติม

ช่องเหล่านี้แสดงเมื่อใส่ API key แล้ว (หรือใช้ Local) และใช้กับ Paid ได้เหมือนกัน

  1. “Set prompt” คำสั่งพิเศษถึง AI เช่น สไตล์การแปล ปล่อยว่างเพื่อใช้คำสั่งในตัว บันทึกแยกตามภาษาและโมเดล ตัวเลขใต้ช่องคือจำนวนตัวอักษร
  2. ปุ่มของ prompt ↶ ↷ ย้อนกลับ/ไปข้างหน้าระหว่างเวอร์ชัน · 🗗 เปิดหน้าแก้ไขเต็มจอ (Prompt Studio) · ⤢ ขยายช่อง · ⟲ โหลดคำสั่งในตัวกลับมา
  3. 🗑 ล้างความจำ ลบความจำของเรื่องที่เปิดอยู่ในแท็บปัจจุบัน
  4. “Story memory mode” ให้ AI จำเรื่องเพื่อแปลชื่อและคำเฉพาะให้ตรงกันทุกตอน
    • “Off” ไม่จำ
    • “Terms only” จำคำเฉพาะ
    • “Full (+ characters)” จำเนื้อเรื่องและตัวละครด้วย
    บรรทัดใต้ช่องบอกว่าจำอะไรไว้แล้วบ้าง ถ้าเป็นแถบสีเหลือง “Series not recognised on this page…” แปลว่าหน้านี้ระบุเรื่องไม่ได้ ความจำจะไม่ถูกใช้ร่วมกัน
  5. “Use human translation examples” ให้ AI ใช้ตัวอย่างคำแปลที่คนแปล (อังกฤษ ญี่ปุ่น และไทย) เป็นแนวทาง บันทึกแยกตามโมเดล
  6. “Send page image to AI” ส่งภาพทั้งหน้าให้ AI ดูด้วย อาจใช้เวลาและค่าใช้จ่ายมากขึ้น ใช้ได้เฉพาะโมเดลที่ยืนยันว่ารับภาพได้ ถ้าไม่ได้ ช่องจะเป็นสีจางและกดไม่ได้ ชี้ที่ชื่อเพื่อดูเหตุผล
  7. “Set a token ceiling” กำหนดขนาดสูงสุดของแต่ละคำขอ ค่าสูงขึ้น = ส่งข้อความต่อครั้งมากขึ้น จำนวนครั้งน้อยลง แต่ถ้าสูงเกินที่โมเดลตอบได้ คำตอบอาจไม่ครบและล้มเหลว ปิดไว้ = ใช้ค่าเริ่มต้น (ค่าเริ่มต้นของโมเดลที่เลือกดูได้เมื่อชี้ที่ชื่อ หรือในช่องตัวเลข)
  8. “AI request mode” ระบบเลือกให้อัตโนมัติ: Cloud ใช้ “Conversation”, Local ใช้ “Independent” เปลี่ยนเองไม่ได้

6AI บนเครื่อง (Local)

ถ้าคุณติดตั้งโปรแกรม AI ไว้บนคอมพิวเตอร์ เลือกจากกลุ่ม “Local” ได้เลย ไม่ต้องมี API key ต้องเปิดโปรแกรมนั้นไว้ก่อนแปล

  1. “Provider” เลือกโปรแกรม เช่น Ollama, LM Studio, Jan, KoboldCpp, llama.cpp หรือ “Custom local adapter”
  2. “Local server URL” ที่อยู่ของโปรแกรมบนเครื่อง ระบบใส่ค่าเริ่มต้นให้ ลิงก์ “(website)” เปิดเว็บไซต์ของโปรแกรม
  3. “Refresh models” ดึงรายชื่อโมเดลจากโปรแกรมใหม่ เช่น หลังโหลดโมเดลเพิ่ม
  4. “Model (required)” เลือกโมเดลที่ติดตั้งไว้
  5. “Local AI capacity” จำนวนคำขอพร้อมกัน: “Auto (recommended)” แนะนำ · “Safe — 1 request” ทีละคำขอ · “Manual” เลือกเองที่ “Simultaneous requests” 1–4

7Paid (ใช้เครดิต TP)

เข้าสู่ระบบด้วยอีเมล

  1. “AI service” เลือก “Paid · TextPhantom credits”
  2. “Email address” ใส่อีเมลของคุณ
  3. “Continue with email” ระบบส่งรหัสไปที่อีเมล ใช้ครั้งแรกจะสร้างบัญชีให้หลังยืนยันรหัส
  1. “6-digit code” ใส่รหัส 6 หลักจากอีเมล ถ้าไม่ได้รับภายในหนึ่งนาที ให้ดูในโฟลเดอร์สแปมหรือจดหมายขยะ
  2. “Verify & sign in” ยืนยันรหัสและเข้าสู่ระบบ
  3. “Change email” กลับไปแก้อีเมล
  4. “Resend code” ขอรหัสใหม่ (ต้องรอเวลานับถอยหลังก่อน)

บัญชี เครดิต และโมเดล

  1. “Available credits” เครดิต TP ที่ใช้ได้ “Reserved” คือเครดิตที่ถูกจองไว้ชั่วคราวระหว่างแปล ส่วนที่ไม่ได้ใช้จะคืนให้
  2. “Buy credits” ซื้อเครดิตเพิ่ม (ดูขั้นตอนในหัวข้อ 8)
  3. “Account details” ดูบัญชี ประวัติ และค่าใช้จ่ายจริงของแต่ละครั้ง
  4. “Translation source” “TP Model” ใช้โมเดลของ TextPhantom (หักเครดิต TP) หรือ “Login” ใช้บัญชี AI ของคุณ (ดูหัวข้อ 9) ช่องนี้แสดงเฉพาะบัญชีที่มีสิทธิ์ AI Login
  5. “Translation model” กดเพื่อเปิดรายการโมเดลพร้อมช่องค้นหา (ดูภาพถัดไป)
  6. “Input” / “Output” ราคาโดยประมาณเป็น TP ต่อ 1,000 โทเคน Input คือข้อความที่ส่งไป Output คือคำตอบ (อาจรวมการคิดของ AI) เครื่องหมาย ≈ แปลว่าประมาณ ส่วน ≤ แปลว่าไม่เกินราคานี้ ค่าจริงคิดจากการใช้งานจริง
  7. “How credits are calculated” กดอ่านวิธีคิดเครดิต
  8. “Refresh balance” โหลดยอดเครดิตและราคาล่าสุด
  9. “Sign out” ออกจากระบบบนเครื่องนี้ ยอดเครดิตใช้ร่วมกันทุกเครื่อง
  1. ช่องค้นหา พิมพ์ชื่อหรือรหัสโมเดล (ทุกคำที่พิมพ์ต้องตรง) กด Enter เพื่อเลือกตัวแรก ลูกศรลงเพื่อเลื่อน Esc เพื่อปิด
  2. แถวโมเดล กดเพื่อเลือกโมเดลนั้น
  3. หัวตาราง “Model” ชื่อ · “Input” และ “Output” ราคาประมาณ TP ต่อ 1,000 โทเคน

หน้าจอขออนุญาตใช้ข้อมูล

Paid, Login และแชทกับแอดมินใช้บัญชี TextPhantom ของคุณ จึงต้องกดอนุญาตก่อน หน้าจอ “ขออนุญาตใช้ข้อมูล” จะขึ้นเมื่อคุณเลือก “AI service” เป็น Paid, เมื่อกด “Continue with email” หรือเมื่อกดปุ่มของบัญชีที่เป็นสีเทา กด “อนุญาต” เพื่อใช้งานต่อ ถ้ากด “ไม่อนุญาต” จะไม่มีอะไรถูกส่งออกไป และการแปลภาพแบบอื่นยังใช้ได้ตามปกติ

ถ้าเข้าสู่ระบบไว้แต่ยังไม่อนุญาต คุณยังเข้าสู่ระบบอยู่ แต่ปุ่มของบัญชีจะเป็นสีเทา และมีแถบ “ยังไม่อนุญาตข้อมูลบัญชี…” (อังกฤษ: “Account data is not allowed…”) ให้กด “ดูและอนุญาต” (Review and allow) ส่วน “Sign out” ใช้ได้เสมอ อ่านว่าส่งข้อมูลอะไร ไปที่ไหน และยกเลิกการอนุญาตได้ที่แท็บ Privacy & data

เมื่อใช้ Paid ช่อง “AI thinking”, “Set prompt”, “Series memory”, “Send page image to AI” และ “Set a token ceiling” ยังใช้ได้ ทำงานเหมือนหัวข้อ 5 ถ้าเปลี่ยน “AI thinking” หรือ “Send page image to AI” ราคาจะถูกตรวจใหม่

8ซื้อแพ็กเครดิต TP

ต้องเข้าสู่ระบบ Paid ก่อน (หัวข้อ 7) จ่ายเงินเป็นบาทผ่าน Stripe เครดิตเข้าบัญชีเองหลังระบบตรวจกับ Stripe ว่าจ่ายแล้ว ไม่ต้องส่งสลิปหรือแจ้งโอน

ขั้นที่ 1 เลือกแพ็ก

ที่แท็บ “AI settings” กด “Buy credits” (ใต้ยอดเครดิต) หน้าต่างจะกว้างขึ้นและเปิดหน้า “Buy credits”

  1. “Buy credits” แท็บซื้อเครดิต แท็บอื่นในหน้านี้: “Account” ยอดเครดิตและรายการล่าสุด · “Orders” รายการสั่งซื้อและการชำระ · “Activity” ประวัติการใช้เครดิต (แท็บ “Refunds” จะปรากฏหลังเคยขอคืนเงิน)
  2. “Available” เครดิตที่ใช้ได้ตอนนี้
  3. การ์ดแพ็ก ชื่อแพ็ก ราคาเป็นบาท จำนวนเครดิต TP และอายุเครดิต เช่น “Valid for 12 months after credits are issued.” คือใช้ได้ 12 เดือนนับจากวันที่เครดิตเข้า ถ้ามีหลายแพ็กให้เลื่อนลงเพื่อดูทั้งหมด
  4. “Select package” สร้างรายการสั่งซื้อแพ็กนั้นและไปหน้าชำระเงิน (ขั้นที่ 2) ถ้ามีรายการของแพ็กนี้ที่ยังรอจ่ายอยู่ ปุ่มจะเป็น “View payment” เพื่อเปิดรายการเดิม ไม่สร้างรายการใหม่
  5. “How payment works” กดอ่านสรุปวิธีชำระ (และช่องทางติดต่อ “Support: …” ถ้าผู้ดูแลตั้งไว้)
  6. “Back” กลับไปหน้าต่าง TextPhantom ตามเดิม
  7. “Reload” โหลดข้อมูลบัญชี แพ็ก และรายการล่าสุดอีกครั้ง

ถ้าเห็น “Payments are not available yet.” หรือ “New purchases are currently closed.” แปลว่าตอนนี้ยังซื้อไม่ได้ ปุ่ม “Select package” จะกดไม่ได้ ส่วนเครดิตและรายการเดิมยังอยู่ครบ

ขั้นที่ 2 จ่ายเงินบนหน้า Stripe

หลังกด “Select package” สถานะเป็น “Preparing payment” ระหว่างเตรียมรายการกับ Stripe เมื่อพร้อม หน้าชำระเงินของ Stripe (checkout.stripe.com) จะเปิดในแท็บใหม่ให้เอง

  1. “Selected package · …” สรุปแพ็กที่เลือก จำนวนเครดิต ราคา และอายุเครดิต ตรวจก่อนจ่าย
  2. “Payment status”
    • “Preparing payment” กำลังเตรียมหน้าชำระ
    • “Ready to pay” จ่ายได้แล้ว
    • “Confirming payment” Stripe กำลังยืนยันการจ่าย
    • “Credits added” เครดิตเข้าบัญชีแล้ว (ขั้นที่ 3)
  3. “Open Stripe checkout” เปิดหน้าชำระของ Stripe อีกครั้ง ใช้เมื่อหน้า Stripe ไม่เปิดเอง (จะมีข้อความ “Stripe could not be opened automatically. Use Open Stripe checkout to continue.”) หรือเมื่อปิดหน้า Stripe ไปก่อนจ่ายเสร็จ
  4. “Check payment status” ให้ระบบตรวจกับ Stripe อีกครั้ง ใช้รายการเดิม ไม่เรียกเก็บเงินซ้ำ
  5. “Cancel this payment” ยกเลิกรายการนี้ (ถ้ายังไม่ได้จ่าย) การยกเลิกเสร็จเมื่อ Stripe ยืนยัน แล้วหน้าจะกลับไปที่รายการแพ็ก
  6. “Order details” เลขอ้างอิงรายการ (“Order reference”) เวลาหมดอายุของลิงก์ชำระ (“Payment link expires”) และ “Support code” เมื่อมีปัญหา
  7. “Back to packages” กลับไปหน้ารายการแพ็ก รายการที่ยังไม่จ่ายยังอยู่

บนหน้า Stripe

หน้านี้เป็นเว็บของ Stripe จึงไม่มีภาพในคู่มือ ตรวจชื่อแพ็กและยอดเงิน (บาท) แล้วเลือกวิธีจ่ายที่ Stripe แสดง เช่น บัตร หรือ PromptPay แล้วทำตามขั้นตอนบนหน้านั้น

หลังจ่ายเสร็จ

Stripe จะพาไปหน้า “Checking your payment” ของ TextPhantom ปิดแท็บนั้นได้ ถ้าปิดหน้า Stripe โดยยังไม่จ่าย จะเห็น “Payment page closed” รายการยังเปิดอยู่ กลับมาจ่ายต่อหรือยกเลิกได้

หน้าต่าง TextPhantom ปิดไป

รายการไม่หาย เปิดหน้าต่าง TextPhantom › “AI settings” › “Buy credits” จะเห็น “You have a pending payment” กด “Resume payment” เพื่อดูสถานะหรือจ่ายต่อ

ขั้นที่ 3 รอเครดิตเข้า

เมื่อ Stripe ยืนยันการจ่าย ระบบเพิ่มเครดิตให้เอง ถ้าเปิดหน้านี้ค้างไว้ สถานะจะอัปเดตเอง (ตรวจซ้ำเป็นระยะประมาณ 9 นาที และตรวจอีกครั้งเมื่อกลับมาที่หน้านี้) ถ้าสถานะยังไม่เปลี่ยน กด “Check payment status”

  1. “Credits added” จ่ายสำเร็จและเครดิตเข้าบัญชีแล้ว
  2. “Payment confirmed” บอกจำนวนเครดิตที่เพิ่ม เช่น “30,000 TP added to your account.”
  3. “View account” ไปแท็บ “Account” เพื่อดูยอดและรายการล่าสุด
  4. “Available now” ยอดเครดิตที่ใช้ได้หลังเติม ยอด “Available credits” ในแท็บ “AI settings” อัปเดตตามด้วย

ดูรายการย้อนหลังได้ที่แท็บ “Orders”: กด “View payment” เพื่อดูหรือตรวจรายการที่ยังไม่เสร็จ หรือ “View receipt” สำหรับรายการที่เครดิตเข้าแล้ว

ถ้าจ่ายแล้วยังไม่สำเร็จ

สถานะค้างที่ “Confirming payment”
Stripe ยังยืนยันไม่เสร็จ เครดิตจะเข้าหลังยืนยัน กด “Check payment status” ภายหลังได้ ไม่เกิดการเรียกเก็บซ้ำ
“Payment needs attention” หรือ “Payment failed”
ผู้ดูแลต้องตรวจรายการนี้กับ Stripe ก่อน ติดต่อผู้ดูแลด้วย “Contact admin” ในแท็บ “Tools” แจ้ง “Order reference” และ “Support code” จาก “Order details”
“This checkout link has expired.” หรือสถานะ “Instructions expired” / “Cancelled”
ลิงก์ชำระนั้นใช้ไม่ได้แล้ว กด “Check payment status” ก่อน (ถ้ามีปุ่ม) เพื่อให้แน่ใจว่ายังไม่ได้จ่าย แล้วกลับไปที่ “Buy credits” เพื่อเลือกแพ็กใหม่
สร้างรายการใหม่ไม่ได้ (ให้รอหรือมีรายการรอมากเกินไป)
ระบบจำกัดการสร้างรายการติดกันเร็ว ๆ และจำนวนรายการที่รอจ่าย เปิดรายการเดิมจาก “Resume payment” หรือแท็บ “Orders” เพื่อจ่ายต่อหรือยกเลิกก่อน

ขอคืนเงิน

ถ้าผู้ดูแลเปิดให้ขอคืนเงินเองได้ ในแท็บ “Orders” › “Confirmed payments” จะมีกล่อง “Request a refund” บอกเครดิตที่ยังไม่ได้ใช้ (“Unused”) ยอดเงินที่คาดว่าจะได้คืน (“Estimated refund”) และกำหนดเวลา (“Request deadline”) กด “Refund unused credits” แล้วกดยืนยัน

  • คืนเฉพาะเครดิตที่ซื้อและยังไม่ได้ใช้จากการจ่ายครั้งนั้น ในราคาเดิม ไม่รวมเครดิตโบนัสและเครดิตทดลอง และต้องขอภายในเวลาที่แสดง
  • ระหว่างคำนวณและยืนยันการคืนเงิน Paid จะหยุดชั่วคราว ยอดคืนสุดท้ายอาจต่างจากที่ประมาณไว้
  • ติดตามสถานะที่แท็บ “Refunds” ถ้าขึ้น “Bank details needed” ให้ดูอีเมลจาก Stripe แล้วกรอกข้อมูลบัญชีธนาคาร
  • ถ้าไม่มีปุ่ม “Refund unused credits” ข้อความในกล่องจะบอกเหตุผล เช่น เลยเวลาขอคืนแล้ว ให้ติดต่อผู้ดูแลในแชท

9Login (ใช้บัญชี AI ของคุณ)

ต้องเข้าสู่ระบบ Paid ก่อน (หัวข้อ 7) และบัญชีต้องมีสิทธิ์ AI Login จึงจะเห็นช่อง “Translation source” การแปลใช้โควตาบัญชีผู้ให้บริการของคุณ ไม่ใช้เครดิต TP

  1. “Translation source” เลือก “Login”
  2. “Provider” เลือก ChatGPT, Claude, Gemini หรือ DeepSeek ข้อความต่อท้าย เช่น “· Checking…” หรือ “· Unavailable” บอกสถานะของผู้ให้บริการนั้น
  3. คำอธิบายเมื่อชี้ที่ชื่อ “Provider” Claude และ ChatGPT ใช้แท็บในเบราว์เซอร์นี้ การแปลทำผ่านแท็บ claude.ai หรือ chatgpt.com เว็บละ 1 แท็บ ถ้าเปิดไว้แล้วระบบใช้แท็บนั้น ถ้ายังไม่มีระบบเปิดให้ 1 แท็บเบื้องหลัง ระบบไม่ปิดแท็บเอง ปิดเองได้เมื่อไม่ใช้แล้ว ใช้แท็บอื่นต่อได้ตามปกติ ต้องเปิดเบราว์เซอร์ค้างไว้และล็อกอินเว็บนั้นไว้ ถ้าปิดแท็บนั้นระหว่างแปล การแปลจะหยุด เมื่อเชื่อมต่อแล้ว จะมีแถบสีเหลืองใต้ช่องเตือนให้เปิดแท็บนั้นค้างไว้ระหว่างแปล
  4. “Sign in” เริ่มเชื่อมต่อบัญชี กดครั้งแรกครั้งเดียว เบราว์เซอร์อาจถามสิทธิ์เข้าถึงข้อมูลการเข้าสู่ระบบของเว็บผู้ให้บริการ ให้กดอนุญาต แล้วทำตามขั้นตอนในแท็บของเว็บนั้น หลังจากนั้นถ้ากดแปลตอนยังไม่ได้เชื่อมต่อ (เช่น หลัง API เริ่มใหม่) ระบบจะเชื่อมต่อให้เองและขึ้น “กำลังเชื่อมต่อ…” ที่มุมขวาล่าง แล้วเริ่มแปลเอง ระหว่างรอ ปุ่มเป็น “Waiting for sign-in…” และมีปุ่ม “Cancel” ให้ยกเลิก เมื่อเชื่อมต่อแล้ว ปุ่มเป็น “Reconnect” มีช่อง “Model” ให้เลือก และปุ่ม “Logout”
  5. “Refresh” ตรวจสถานะและรายชื่อโมเดลอีกครั้ง
  6. บรรทัดสถานะ บอกขั้นตอนที่กำลังทำ หรือเหตุผลเมื่อไม่สำเร็จ
  • “Logout” ตัดการเชื่อมต่อกับ TextPhantom เท่านั้น คุณยังล็อกอินเว็บไซต์นั้นในเบราว์เซอร์ตามเดิม
  • บางเว็บไซต์เลือกการคิดของ AI เอง ช่อง “AI thinking” จะถูกล็อก ชี้ที่ชื่อช่องเพื่อดูเหตุผล

10แท็บ Tools

  1. “Select images” เลือกไฟล์ภาพในเครื่องมาเปิดในหน้าดูภาพของ TextPhantom เพื่อแปล
  2. “Select folder” เปิดทั้งโฟลเดอร์ (ใน Brave ต้องเปิด brave://flags/#file-system-access-api ก่อน)
  3. “Auto translate” เปิดแท็บใหม่สำหรับวาง ลาก หรืออัปโหลดภาพทีละภาพ แท็บนี้มีโหมด ภาษา และแหล่งแปลของตัวเอง
  4. “Custom API URL” ที่อยู่เซิร์ฟเวอร์ ปล่อยว่าง (ช่องขึ้นว่า “Default server”) เพื่อใช้เซิร์ฟเวอร์เริ่มต้น (ถ้าเป็นเซิร์ฟเวอร์ในเครื่องหรือในวงแลน จะมีช่อง “Remove server pacing for this local API” เพิ่มใต้ช่องนี้)
  5. ⟲ กลับไปใช้เซิร์ฟเวอร์เริ่มต้น
  6. “Send diagnostic logs to the API server” อยู่ใต้ช่อง “Custom API URL” ปิดเป็นค่าเริ่มต้น เปิดเฉพาะตอนผู้พัฒนาขอให้ช่วยตรวจปัญหา (มีหน้าต่างถามยืนยันก่อนเปิด) ดูแท็บ Privacy & data
  7. “Where the work runs” ตอนนี้ใช้ได้เฉพาะ “Extension (default)”
  8. “Reset defaults” คืนค่าการตั้งค่าทั้งหมดเป็นค่าเริ่มต้น (มีหน้าต่างถามยืนยันก่อน)
  9. “Contact admin” แชทกับผู้ดูแล TextPhantom แสดงเมื่อเข้าสู่ระบบบัญชี Paid แล้ว และต้องเปิดจากหน้าเว็บทั่วไป ถ้ายังไม่ได้อนุญาตการใช้ข้อมูล ปุ่มนี้เป็นสีเทา กดแล้วจะขออนุญาตก่อน

11ระหว่างแปลบนหน้าเว็บ

  1. ปุ่ม 🔍 บนภาพ (เปิดที่ “Translate buttons on images”) คลิกเพื่อแปลภาพนั้น ระหว่างทำงานปุ่มจะเป็น ⏳
  2. “🔍 Translate all” (เปิดที่ “Translate all images on this page”) ชี้เมาส์หรือแตะแถบเล็ก ๆ ที่ขอบขวาให้ปุ่มเลื่อนออกมา แล้วกดเพื่อแปลทุกภาพในหน้า
  3. กล่องสถานะมุมขวาล่าง บอกความคืบหน้า เช่น “inserted 3/12” คือใส่คำแปลแล้ว 3 จาก 12 ภาพ เมื่อเสร็จจะขึ้นคำว่า “done” แล้วกล่องจะหายไปเองในไม่กี่วินาที
  4. ปุ่ม + เปิดตารางรายละเอียดทีละภาพ กด − หรือปุ่ม Esc เพื่อย่อ

โหลดหน้าเว็บใหม่ (Reload) ไปหน้าอื่น หรือปิดแท็บนั้น งานแปลของแท็บนั้นจะถูกยกเลิก

กล่อง “เครดิตอาจไม่พอ” (Paid)

ถ้าเครดิตอาจไม่พอสำหรับทุกภาพ จะมีกล่องกลางจอบอกจำนวนภาพ เครดิตที่ประมาณว่าจะใช้ และยอดคงเหลือ กด “แปลต่อ” (“Continue”) เพื่อแปลเท่าที่เครดิตพอ ภาพที่เหลือจะแจ้งว่าเครดิตไม่พอ โดยไม่ส่ง AI และไม่หักเครดิต หรือกด “ยกเลิก” (“Cancel”) หรือปุ่ม Esc เพื่อไม่แปล

ภาพที่แปลไม่ได้

จะมีป้ายบนภาพหรือข้อความ “Not translated: …” พร้อมเหตุผลภาษาไทยและรหัส เช่น IMG_NO_TEXT ดูวิธีแก้ในหัวข้อ 12

12แก้ปัญหาที่พบบ่อย

คำถามทั่วไป

ไม่เห็นแท็บ “AI settings”
ที่แท็บ “Translate” ตั้ง “Mode” เป็น “Google Lens (text)” และ “Text output” เป็น “AI translation”
สถานะเป็น ❌ หรือมีกล่อง “API server is offline.”
ตรวจอินเทอร์เน็ต แล้วกด “Open API settings” ในกล่องนั้น (หรือไปที่แท็บ “Tools”) ถ้าไม่ได้ตั้งเซิร์ฟเวอร์เอง ให้กด ⟲ ข้างช่อง “Custom API URL” เพื่อใช้ค่าเริ่มต้น เมื่อเชื่อมต่อได้ การแปลจะกลับมาทำงานเอง
อยากเริ่มใหม่ทั้งหมด
แท็บ “Tools” › “Reset defaults”

ข้อความแจ้งเตือนบนภาพ

ข้อความที่เห็นบนหน้าเว็บจะเป็นภาษาไทยตามด้านล่าง ตามด้วยรหัส ใช้รหัสค้นหาในตารางนี้

ข้อความที่เห็นควรทำอย่างไร
ไม่พบข้อความในภาพIMG_NO_TEXT ภาพนี้ไม่มีตัวอักษรให้แปล ไม่ต้องทำอะไร
เว็บไซต์ไม่อนุญาตให้อ่านภาพนี้IMG_BLOCKED โหลดภาพจากเว็บไซต์ต้นทางไม่ได้IMG_SOURCE_UNREACHABLE โหลดหน้าเว็บใหม่แล้วลองอีกครั้ง ถ้ายังไม่ได้ ให้บันทึกภาพลงเครื่อง แล้วเปิดด้วย “Tools” › “Select images”
เชื่อมต่อเซิร์ฟเวอร์ไม่ได้ กรุณาตรวจอินเทอร์เน็ตNET_OFFLINE เชื่อมต่อ API ไม่ได้—ตรวจว่าเปิดเซิร์ฟเวอร์แล้ว, URL ถูกต้อง และเบราว์เซอร์อนุญาตการเชื่อมต่อAPI_UNREACHABLE ตรวจอินเทอร์เน็ต และดูช่อง “Custom API URL” ในแท็บ “Tools” (ปล่อยว่างหรือกด ⟲ เพื่อใช้ค่าเริ่มต้น)
ยังไม่ได้ตั้งค่า API key [AI settings > API key]AI_KEY_MISSING ยังไม่ได้เลือกโมเดล [AI settings > Model]AI_MODEL_MISSING ไปที่จุดในวงเล็บเหลี่ยม แล้วใส่ API key หรือเลือก Model (หัวข้อ 5)
AI key ใช้งานไม่ได้AI_KEY_INVALID สร้าง key ใหม่จากลิงก์ “(get key)” แล้ววางในช่อง “API key”
ผู้ให้บริการ AI จำกัดการใช้งานชั่วคราวAI_RATE_LIMIT รอสักครู่แล้วแปลใหม่
โควตาหรือเครดิต AI หมด กรุณาเติมเครดิตหรือตรวจแผนการใช้งานAI_QUOTA_EXHAUSTED เติมเงินหรือตรวจแผนบนเว็บไซต์ของบริษัท AI ที่ใช้ หรือเปลี่ยนไปใช้ Paid
เชื่อมต่อ Local AI ไม่ได้—ตรวจว่าเปิดโปรแกรม, URL และ CORS แล้วLOCAL_UNREACHABLE เปิดโปรแกรม AI บนเครื่อง ตรวจ “Local server URL” แล้วกด “Refresh models” (หัวข้อ 6)
กรุณาเข้าสู่บัญชี Paid และเลือกโมเดลที่ AI settingsPAID_LOGIN_REQUIRED เข้าสู่ระบบและเลือก “Translation model” (หัวข้อ 7)
เครดิตไม่พอสำหรับภาพนี้ ยังไม่ได้ส่ง AI และไม่หักเครดิต เติมเครดิตแล้วแปลใหม่ได้PAID_INSUFFICIENT_CREDITS กด “Buy credits” ซื้อเครดิต (หัวข้อ 8) แล้วแปลใหม่
กรุณาเชื่อมต่อบัญชี AI Login และเลือกโมเดลก่อนแปลLOGIN_SESSION_REQUIRED การเชื่อมต่อ AI Login หมดอายุ กรุณาเชื่อมต่อบัญชีใหม่LOGIN_SESSION_EXPIRED แท็บ “AI settings” › Login กด “Sign in” หรือ “Reconnect” แล้วเลือก “Model” (หัวข้อ 9)
ส่วนขยายใช้แท็บเว็บไซต์ AI (claude.ai / chatgpt.com) ในเบราว์เซอร์นี้ไม่ได้ กรุณาเปิดเบราว์เซอร์ค้างไว้ เข้าสู่ระบบเว็บไซต์นั้น แล้วลองใหม่LOGIN_BROWSER_RELAY_UNAVAILABLE เปิดเบราว์เซอร์ค้างไว้ เข้าสู่ระบบ claude.ai หรือ chatgpt.com ในเบราว์เซอร์เดียวกัน แล้วแปลใหม่
แท็บ chatgpt.com ยังไม่พร้อม (เช่น ยังโหลดไม่เสร็จหรือไม่พบช่องพิมพ์) กรุณาเปิด/รีโหลดแท็บ chatgpt.com ปิดหน้าต่างที่บังอยู่ แล้วลองใหม่LOGIN_PROVIDER_NOT_READY แท็บ ChatGPT ยังตอบข้อความอื่นอยู่ กรุณารอสักครู่แล้วลองใหม่LOGIN_TAB_BUSY เปิดหรือรีโหลดแท็บ chatgpt.com ปิดหน้าต่างที่บังช่องพิมพ์ หรือรอให้ตอบเสร็จ แล้วแปลใหม่
บัญชี AI Login ใช้ครบโควตาแล้วชั่วคราว กรุณาลองใหม่ภายหลังหรือเลือกโมเดลอื่นLOGIN_QUOTA_EXCEEDED รอให้โควตาบัญชีกลับมา หรือเลือก “Model” อื่น
การเชื่อมต่อนี้ส่งภาพหน้าไม่ได้ กรุณาปิด Send page image to AILOGIN_IMAGE_UNSUPPORTED ปิดช่อง “Send page image to AI” แล้วแปลใหม่
