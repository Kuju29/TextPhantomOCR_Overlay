Extension decodes Lens, builds the layout, samples colours and draws the overlay in your browser. The API only does three things: the Lens upload, Lens graph grouping, and the AI translation call.
API server is the older split: the server runs Lens, Lens graph grouping, the AI call, the erase, the fonts and the HTML, and sends back a finished overlay or image. Slower per page and it uploads the whole picture, but it needs almost nothing from the browser — useful when a site fights the overlay, when a page is too large for the local renderer, or to compare the two.
Both engines use the same AI contract, the same Lens client and the same per-key pacing, so switching does not change the translation you get.
Custom Local Adapter is Extension-only. Built-in Local AI providers, including llama.cpp, also work with a self-hosted API when the runtime is on that API machine.
