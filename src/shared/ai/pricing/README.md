# AI price accounting

`providers.js` lists verified standard API prices in USD per million tokens with official source links. Do not use a guessed family price for a different model or provider. Provider reported charge wins; snapshots keep the original price and source on the usage record. Users can override exact provider/model prices and the USD/THB conversion rate in the popup. Unknown rates remain unpriced. Local inference has no API fee but can incur hardware/electricity costs; TextPhantom paid credits are separate from the customer's direct API bill.

`calculate.js` treats cached input and cache write as parts of input. It never adds reasoning tokens again to output. Without provider cache counters it presents a full-input **upper bound**, not proof of a cache miss. Google context cache storage and optional ancillary fees are outside token usage, so estimates can differ from invoices. Conversion from Frankfurter is a reference rate, not the credit-card settlement rate.

`live.js` fetches the exact Featherless model price or the Hugging Face model and observed upstream route from their documented public model catalogues, without sending a user's key. Catalogues that reject anonymous requests stay unpriced. Same-day calls may receive a clearly marked later estimate when a catalogue price arrives; prices are never silently rewritten on later changes. OpenRouter's provider-reported USD charge takes priority. Dynamic time-of-day prices, Gemini free tier, Featherless monthly plans, Hugging Face credits, and TextPhantom credit debits require account billing evidence; do not treat a list-price estimate as an invoice.
