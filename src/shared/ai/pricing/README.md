# AI price accounting

`providers.js` lists verified standard API prices in USD per million tokens with official source links. Do not use a guessed family price for a different model or provider. Provider reported charge wins; snapshots keep the original price and source on the usage record. Users can override exact provider/model prices and the USD/THB conversion rate in the popup. Unknown rates remain unpriced. Local inference has no API fee but can incur hardware/electricity costs; TextPhantom paid credits are separate from the customer's direct API bill.

`calculate.js` treats cached input and cache write as parts of input. It never adds reasoning tokens again to output. Missing cache-read counts can yield a full-input upper bound only when that bound is valid. Missing premium cache-write usage, totals or duration leave cost unpriced; writing cache can cost more than ordinary input. Conflicting charges for the same receipt also stay unpriced. Decimal arithmetic preserves the observed digits until display. Google explicit cache storage and optional ancillary fees are outside token usage, so estimates can differ from invoices. Conversion from Frankfurter is a reference rate, not the credit-card settlement rate.

`live.js` fetches an exact, uniquely identified OpenRouter public catalogue model, the exact Featherless model price, or the Hugging Face model and observed upstream route, without sending a user's key. Catalogues that reject anonymous requests stay unpriced. OpenRouter token rates are converted from USD/token to USD/1M with decimal arithmetic, including cache read/write and one-hour write prices. Conditional token thresholds use a strict `>` comparison; later matching entries override individual price axes. UTC daily/weekly windows additionally require an individual provider dispatch timestamp: a positive safe-integer `providerRequestStartedAt` in epoch milliseconds with `providerRequestTimeSource: 'provider_transport'`. Receipt completion timestamps, catalogue fetch times and shared frontend operation start times do not satisfy this evidence contract. Current normal receipts do not retain proven provider dispatch clocks, so new unreported-cost receipts with time-dependent tariffs stay unpriced; queued or multiple turns cannot borrow one operation clock. Provider-reported cost still wins, and historical saved prices remain unchanged. Unsupported conditions and incomplete per-attempt information remain unpriced. Request/image and other ancillary fees are excluded from token estimates and labeled accordingly. The public top-provider catalogue price can differ from the provider actually selected by OpenRouter. Source: https://openrouter.ai/docs/guides/overview/models

Visible popups refresh Paid account/model price data and check Manual public price data every 60 seconds. Hidden or closed popups stop polling. OpenRouter public rates are fetched at most once a minute for an unchanged selection; Featherless/Hugging Face keep their existing twelve-hour rate-fetch interval. Quiet refresh retains the old display and does not overwrite edits in the rates dialog or custom rates. A failed current OpenRouter lookup preserves a prior rate display but leaves new requests without an estimate until a valid rate or provider charge is received. API/account/model changes and selection revisions prevent late replies from replacing the current display.

Paid price snapshots retain safe server quote revisions and `price_sync` display metadata. Cached data never verifies an account or enables Paid actions. Authoritative `automatic` prices must be `current` for normal Paid preflight; older Centers without the metadata remain compatible. Center alone chooses reservation and final TP charges. A cached automatic price is labeled as previously loaded until the account is checked again.

Same-day calls may receive a clearly marked later estimate when a catalogue price arrives; already priced records keep their saved rates on later changes. OpenRouter's provider-reported USD charge takes priority for a normal OpenRouter billed account. OpenRouter BYOK returns an OpenRouter fee and can separately report upstream inference cost: neither field alone is the customer's verified combined bill, so BYOK is excluded from the summed USD/THB price and both amounts appear individually. Gemini free tier, Featherless monthly plans, Hugging Face credits, and TextPhantom credit debits require account billing evidence; do not treat a list-price estimate as an invoice.
